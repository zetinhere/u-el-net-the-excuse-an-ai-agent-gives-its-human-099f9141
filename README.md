One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline. The program drafts several candidate excuses, scores each against the judge's brief (on-subject, funny on first read, believable as an AI agent's own condition, tight, fresh), and writes the best one to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
